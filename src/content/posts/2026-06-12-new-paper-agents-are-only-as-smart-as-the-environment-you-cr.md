New Paper: Agents are only as smart as the environment you create for them.

That is the useful lesson from EurekAgent, a new system from Tsinghua University and Zhipu AI. The researchers did not build a radically new scientist-agent from scratch. They coordinated off-the-shelf coding agents inside a carefully engineered environment: bounded permissions, shared artifacts, budget controls, secure evaluation, and human oversight.  
The results are striking.

Across mathematics, kernel engineering, and machine-learning engineering tasks, EurekAgent set new state-of-the-art results, including a new 26-circle packing result found for less than $11 in total API cost.

But the more important point is architectural. As general-purpose agents get better, the bottleneck shifts from telling the agent exactly what to do to designing the world in which the agent acts.

A weak environment invites reward hacking, evaluation leakage, broken reproducibility, and uncontrolled spend. A strong one turns the same underlying model capability into valid, inspectable, resource-bounded work.

That matters for any company evaluating autonomous agents. The question is no longer just, "How smart is the model? It is: What system makes the model’s work trustworthy?

For AI leaders, this is another sign that we are moving from the demo era into the systems era. The agent is not the product. The environment around the agent is becoming the product.

Paper: EurekAgent: Agent Environment Engineering is All You Need For Autonomous Scientific Discovery, Xin et al.
