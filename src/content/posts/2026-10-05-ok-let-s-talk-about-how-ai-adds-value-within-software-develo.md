OK let's talk about how AI adds value within software development, aka coding. The group of people that most quickly and ardently embraced generative AI have been the first to feel its full effects.

Cursor, Codex, and Claude Code have all totally revolutionized how we write computer code, all in about 18 months. It is mind-boggling what AI can do in this space. But the question remains: is AI adding value to the business? Won't someone think of the shareholders!?

One of the best pieces of evidence we have now is a newly updated working paper, Writing Code vs. Shipping Code: Productivity Effects Across Generations of AI Coding Tools by Mert Demirer, Leon Musolff & Liyuan Yang. They tackle two key questions by reviewing the work of over 500,000 GitHub developers.

First, does AI help at the task level with increasing productivity. Two, if there is an increase in productivity using AI, does the increase pass through to an increase in final output. This is inching closer to the AI Value question. It is a start, and what they found is fascinating.

The answer to the increased productivity question is a resounding YES. What is cool to see is that as the AI tools got better, the productivity increased dramatically.

We've seen three generations of AI coding tools emerge: autocomplete for live code suggestions, sync agents that write and edit right alongside you, and async agents that can take a task and run with it completely on their own. In this huge study, the productivity gains scaled dramatically: autocomplete bumped weekly commits by about 30%, sync agents increased by 180%, and async agents increased commits by 240%.

So something like Claude Code is increasing weekly code commits by nearly 2.5x, which means that question is settled. AI is massively increasing task-level productivity for coders. But what about actual final outputs, like pull requests and new releases. Those results start to get murky.

Sync agents alone raised lines of code by 958% and pull requests by 86%. BUT actual releases only increased by 20%. So the amount of code written went up 10x but actual releases went up by only 1.2x? What is causing this gap?

The large increase in productivity and code production never reaches the final product because of human beings. Code goes through code review by a human being. We didn't increase worked hours by code reviewers by 10x so why would we think code released would go up that much simply because that much more code is being produced?

This is the paradox of AI value right now. It feels like a miracle, and it shows us amazing results. But those gains are quarantined and isolated. Like doing nothing but leg days and never touching your biceps. In coding, the gains are all up front, at the task level. We are not seeing a comparable gain in actual output yet. This leaves us with an uncomfortable answer to the AI Value question. Right now, balancing the books of AI investment vs. returns, you are going to need a lot of red ink.
